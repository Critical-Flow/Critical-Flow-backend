# 5.4 AI 기능 요구사항

본 절은 시스템 내 AI 기능의 외부 동작 요구사항을 정의한다. AI 기능은 학습자가 작성한 노트를 기반으로 소크라테스식 단일 질문을 생성함으로써 학습자의 자기 주도적 사고를 유도하고, 과거 학습 노트 컨텍스트를 검색하여 학습 연속성을 지원하며, 학습 집중도 신호를 보조적으로 참조한다.

AI 기능 전반에 걸쳐 다음 두 가지 원칙이 적용된다. 첫째, 자연어 생성 및 분류 기능은 단일 외부 LLM 서비스 공급자를 통해 수행된다. 둘째, 모든 AI 기능의 입력·출력에는 요청 학습자 본인의 데이터만 포함되어야 하며, 다른 학습자의 데이터가 노출되어서는 아니된다.

본 절은 외부 관찰 가능한 동작 요구사항(WHAT)만을 정의한다. 사용 모델명·파라미터·알고리즘 구현·임계값 수치·내부 식별자 등 구현 수준의 세부 사항은 본 문서의 범위에서 제외된다.

## 5.4.1 AI 기능 목록 및 입출력 명세

### 5.4.1.1 기능 요약표

| 기능 ID | 기능명 | 우선순위 (MoSCoW) | 개요 |
|---|---|---|---|
| AI-001 | AI 튜터 응답 생성 | Must | 학습자 노트를 기반으로 소크라테스식 단일 질문을 생성하여 자기 주도 사고를 유도 |
| AI-002 | 질문 유형 분류 | Must | 학습자 노트를 정의된 질문 유형(6종) 중 하나로 분류 |
| AI-003 | 노트 임베딩 및 관련 노트 검색 | Must | 학습자 자신의 과거 노트 중 현재 학습과 관련된 컨텍스트를 검색하여 반환 |

### 5.4.1.2 기능별 상세 명세

#### AI-001 AI 튜터 응답 생성

**액터:** 학습자 (직접), AI 튜터 시스템 (간접)  
**트리거:** 학습자가 AI 튜터 대화 세션에서 메시지를 전송하거나 대화가 최초 시작될 때  
**목적:** 학습자가 현재 학습 중인 노트 내용을 깊이 이해할 수 있도록 사고를 유도하는 단일 질문 또는 세션 요약을 반환

**주요 사용자 시나리오:**
- 학습자가 새 노트에 대해 대화를 시작하면, 시스템은 노트 내용을 분석하여 첫 번째 소크라테스식 질문을 생성한다.
- 학습자가 답변을 전송하면, 시스템은 대화 이력과 현재 노트를 바탕으로 후속 질문을 생성한다.
- 누적 질문 횟수가 최대 연속 질문 횟수에 도달하면, 시스템은 질문 대신 세션 학습 요약을 반환한다.
- 학습자가 무의미 발화를 전송하면, 시스템은 직전 질문을 재제시한다.

**입력 (외부 계약)**

| 필드 | 타입 | 필수 여부 | 출처 |
|---|---|---|---|
| 대화 식별자 | 정수 (64비트) | 필수 | URL 경로 |
| 학습자 메시지 | 문자열 | 조건부 필수 (첫 질문 생성 시 불필요) | 요청 본문 |
| 현재 노트 본문 | 문자열 (마크다운) | 필수 | 대화에 연결된 노트 |
| 관련 노트 컨텍스트 항목 목록 | 문자열 목록 | 선택 (없을 수 있음) | AI-003 검색 결과 |
| 학습 집중도 신호 | 이벤트 목록 (유형·지속 시간) | 선택 (없을 수 있음) | 학습 세션 이벤트 기록 |
| 질문 유형 | 열거형 (6종) | 필수 | AI-002 분류 결과 |
| 누적 질문 수 | 정수 (0 이상) | 필수 | 대화 이력 |
| 코드 포함 여부 | 불리언 | 필수 | 현재 노트 본문 분석 결과 |

**출력 (외부 계약)**

| 필드 | 타입 | 설명 |
|---|---|---|
| 응답 본문 | 문자열 | 단일 질문 텍스트 또는 세션 요약 텍스트 |
| 응답 모드 | 불리언 | 요약 응답 모드 여부 (true이면 세션 질문 생성이 종료되었음을 의미) |
| 갱신된 누적 질문 수 | 정수 | 이번 응답 후의 누적 질문 횟수 |

**행동 계약**

- 시스템은 한 응답에 정확히 하나의 질문만을 포함하여야 한다. (요약 응답 모드 제외)
- 시스템은 응답에 완성된 코드, 직접 정답, 또는 정답과 동치인 설명을 포함하지 아니하여야 한다.
- 학습자 메시지가 무의미 발화에 해당하는 경우, 시스템은 직전 AI 질문을 재제시하여야 한다. 무의미 발화의 판정 기준은 길이 기준 및 어휘 목록 기준으로 구성된다.
- 누적 질문 수가 최대 연속 질문 횟수 [TBD: 운영 정책에 따라 확정] 이상이 되는 경우, 시스템은 요약 응답 모드로 전환하여야 한다. 요약 응답 모드에서는 질문을 생성하지 아니하여야 한다.

**실패 시 외부 동작**

| 실패 유형 | 외부 동작 | HTTP 상태 코드 |
|---|---|---|
| 외부 LLM 서비스 타임아웃 또는 오류 | 학습자에게 재시도를 안내하는 메시지를 반환하여야 한다 | 502 Bad Gateway |
| 빈 응답 수신 | 학습자에게 재질문 유도 메시지를 반환하여야 한다 | 200 OK |
| 대화 식별자가 존재하지 않는 경우 | 오류 메시지를 반환하여야 한다 | 404 Not Found |

#### AI-002 질문 유형 분류

**액터:** AI 튜터 시스템 (AI-001 응답 생성 요청 시 자동 선행 수행)  
**트리거:** AI-001 응답 생성 요청 시 자동 수행  
**목적:** 학습자 노트의 특성에 맞는 질문 유형을 선택하여 AI-001에 전달

**질문 유형 정의 (6종)**

| 유형 번호 | 적용 조건 |
|---|---|
| 유형 1 | 노트에 새로운 용어나 개념이 처음 등장하며 설명이 부족한 경우 |
| 유형 2 | 노트에 특정 방식이나 기술을 선택한 이유, 트레이드오프, 비교가 포함된 경우 |
| 유형 3 | 이전에 학습한 개념과 현재 노트가 연결되는 경우 (관련 노트 컨텍스트가 존재할 때만 선택 가능) |
| 유형 4 | 기본 개념 이해 후 엣지케이스, 실패 케이스, 경계 조건을 탐구할 수 있는 경우 |
| 유형 5 | 노트에 코드 블록이 포함된 경우 (최우선 적용) |
| 유형 6 | 코드 없이 이론·개념만 설명된 순수 텍스트 노트인 경우 |

**입력 (외부 계약)**

| 필드 | 타입 | 필수 여부 | 출처 |
|---|---|---|---|
| 현재 노트 본문 | 문자열 (마크다운) | 필수 | 대화에 연결된 노트 |
| 관련 노트 컨텍스트 존재 여부 | 불리언 | 필수 | AI-003 검색 결과 |

**출력 (외부 계약)**

| 필드 | 타입 | 설명 |
|---|---|---|
| 질문 유형 | 열거형 (6종) | 정의된 6가지 질문 유형 중 하나 |

**행동 계약**

- 시스템은 정의된 6종 질문 유형 외의 값을 출력하지 아니하여야 한다.
- 분류에 실패하는 경우, 시스템은 안전한 기본 질문 유형으로 폴백하여야 한다.
- 관련 노트 컨텍스트가 필요한 유형이 분류되었으나 해당 컨텍스트가 없는 경우, 시스템은 안전한 대체 유형으로 폴백하여야 한다.

**실패 시 외부 동작**

| 실패 유형 | 외부 동작 |
|---|---|
| 분류 실패 또는 외부 LLM 오류 | 안전한 기본 질문 유형으로 폴백하여 AI-001 호출이 정상 수행되어야 한다 |

#### AI-003 노트 임베딩 및 관련 노트 검색

**액터:** AI 튜터 시스템 (AI-001·AI-002 선행 수행), 노트 서비스 (노트 저장·수정·삭제 시 자동 수행)  
**트리거:** 노트 저장·수정 시 임베딩 갱신; AI 튜터 응답 생성 요청 시 관련 노트 검색 수행  
**목적:** 학습자의 과거 노트 중 현재 학습과 관련된 컨텍스트를 검색하여 AI-001에 제공

**입력 (외부 계약) — 관련 노트 검색**

| 필드 | 타입 | 필수 여부 | 출처 |
|---|---|---|---|
| 쿼리 텍스트 | 문자열 | 필수 | 현재 노트 본문 |
| 사용자 식별자 | 정수 (64비트) | 필수 | 인증 컨텍스트 |
| 제외 노트 식별자 | 정수 (64비트) | 필수 | 현재 노트 |

**출력 (외부 계약)**

| 필드 | 타입 | 설명 |
|---|---|---|
| 관련 노트 컨텍스트 항목 목록 | 객체 목록 | 관련도 임계값 이상인 과거 노트 항목들 (없으면 빈 목록) |
| ↳ 제목 | 문자열 | 해당 노트의 제목 |
| ↳ 세션 식별자 | 문자열 | 해당 노트가 속한 학습 세션 식별자 |
| ↳ 본문 일부 | 문자열 | 해당 노트의 관련 내용 발췌 |
| ↳ 관련도 점수 | 실수 | 현재 노트와의 관련도 수치 |

**행동 계약**

- 검색 결과에는 요청한 학습자 본인의 노트만 포함되어야 한다. 다른 학습자의 노트가 결과에 포함되어서는 아니된다.
- 제외 노트 식별자에 해당하는 노트는 결과에 포함되지 아니하여야 한다.
- 관련도가 임계값 [TBD: 측정 실험 결과에 따라 확정] 미만인 항목은 결과에서 제외하여야 한다.
- 동일한 노트가 결과 목록에 중복으로 포함되어서는 아니된다.
- 노트 저장 또는 수정 시, 해당 노트에 대한 기존 임베딩은 새 임베딩으로 교체되어야 한다.
- 노트 삭제 시, 해당 노트의 임베딩은 검색 대상에서 즉시 제거되어야 한다.

**실패 시 외부 동작**

| 실패 유형 | 외부 동작 |
|---|---|
| 벡터 스토어 검색 오류 | 빈 관련 노트 컨텍스트를 반환하되 AI-001 호출은 정상 수행되어야 한다 |
| 임베딩 저장 오류 | 노트 저장은 성공으로 처리하되, 임베딩 실패를 로깅하여야 한다 |

## 5.4.2 검증·안전·신뢰성 요구사항

| 요구사항 ID | 설명 | 검증 방법 | 실패 시 동작 |
|---|---|---|---|
| REQ-AIV-001 | 노트 본문 입력의 길이가 허용 범위 [TBD: 운영 부하 측정 후 확정]를 초과하는 경우, 요청을 거부하여야 한다. | 경계값 입력으로 API 호출하여 응답 코드 검증 | 400 Bad Request 반환 |
| REQ-AIV-002 | 대화 식별자가 존재하지 않거나 요청 학습자 소유가 아닌 경우, 요청을 거부하여야 한다. | 타 사용자 대화 식별자로 API 호출하여 응답 코드 검증 | 404 Not Found 또는 403 Forbidden 반환 |
| REQ-AIV-003 | 학습자 메시지가 무의미 발화에 해당하는 경우, 시스템은 직전 AI 질문을 재제시하는 응답을 반환하여야 한다. 무의미 발화의 판정 기준은 길이 기준 및 어휘 목록 기준으로 구성된다. | 정의된 무의미 발화 목록으로 API 호출 후 응답에 직전 질문이 포함되는지 검증 | 직전 AI 질문 재제시 응답 반환 |
| REQ-AIV-004 | 관련 노트 검색 결과에는 요청 학습자 본인의 노트만 포함되어야 한다. 다른 학습자의 노트는 어떤 경우에도 결과에 포함되어서는 아니된다. | 학습자 A의 자격증명으로 학습자 B의 노트와 유사한 쿼리를 전송하고 응답 내 노트 소유자 확인 | 타 학습자 노트 미반환 |
| REQ-AIV-005 | 관련 노트 검색 결과에는 현재 조회 중인 노트 자신이 포함되어서는 아니된다. | 현재 노트 내용과 동일한 쿼리로 검색 요청 후 결과 내 해당 노트 식별자 미존재 검증 | 현재 노트 미반환 |
| REQ-AIV-006 | 관련도 임계값 미만의 항목은 관련 노트 검색 결과에서 제외되어야 한다. 임계값 변경 시 관련 노트 검색 재현율 회귀 측정을 수행하여야 한다. | 임계값 변경 전후 관련 노트 검색 재현율 비교 측정 | 임계값 미달 항목 미반환 |

- **Dense-only 모드**: `bm25-max-results: 0` 설정 → Sparse 비활성화
- **하이브리드 모드**: `bm25-max-results: 10` 설정 (기본값)

## Recall@4 계산

```
Recall@4 = (Top-4에 포함된 정답 노트 수) / (전체 정답 노트 수)
```

예: 정답이 4개인데 Top-4에 2개 포함 → Recall@4 = 2/4 = 0.50

| 하이브리드 < Dense | 2차 필터 설정 재검토 |
